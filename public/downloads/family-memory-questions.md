# 가족 기록 인터뷰 20문항
꿈책방·하루기록 무료 샘플 · 2026-10-05

시작 전 동의: 녹음 여부 / 책의 공개 범위 / 사진 권리 / 이름 표시 / 최종 검수 / 삭제 요청 방법을 함께 정합니다. 공개하지 않을 이야기는 기록하지 않습니다.

1. 어릴 적 집은 어떤 모습이었나요?
2. 기억나는 학교길은 어디였나요?
3. 가장 많이 함께한 사람은 누구인가요?
4. 가족의 특별한 음식은 무엇인가요?
5. 첫 일을 시작한 날은 어땠나요?
6. 일을 배우며 기억하는 조언이 있나요?
7. 삶의 방향을 바꾼 선택이 있었나요?
8. 함께 지킨 가족의 약속은 무엇인가요?
9. 이 사진을 찍은 장소와 날짜는 무엇인가요?
10. 사진에 없는 사람의 이야기도 있나요?
11. 이사한 장소마다 달라진 것은 무엇인가요?
12. 어려운 시기에 힘이 된 것은 무엇인가요?
13. 자녀에게 처음 배운 것은 무엇인가요?
14. 오래 보관한 물건과 이유는 무엇인가요?
15. 꼭 남기고 싶은 일상은 무엇인가요?
16. 잘못 알려진 일을 바로잡고 싶나요?
17. 확인이 필요한 날짜·이름은 무엇인가요?
18. 이 기록을 누구에게 전하고 싶나요?
19. 공개하지 않을 부분은 무엇인가요?
20. 마지막 페이지에 어떤 말을 남기고 싶나요?

목차 예시: 어린 시절 → 일과 사람 → 가족의 일상 → 사진 이야기 → 다음 세대에게. 사실·추억·추정을 구분하고 당사자 최종 검수를 받은 뒤 공개하세요.
